# Deforestation Research — Colombia and Brazil

I worked on deforestation research for WWF, focusing on Colombia and the Brazilian Amazon. This repository contains my original R scripts, updated versions with configurable file paths, and the model comparison table from the Colombia analysis.

## Colombia

For Colombia, I used binomial generalized linear models to examine relationships between deforestation and variables such as slope, elevation, roads, rivers, nearby cities, protected areas, and land cover.

I compared four model specifications: a full model, a stepwise model, an elevation-only model, and a residual-autocovariate (RAC) model.

The [Colombia model comparison table](tables/colombia-glm-model-comparison.csv) contains the coefficients from that analysis.

The original work also includes a deforestation-risk map produced using Random Forest. That map is separate from the GLM analysis.

[View the original Colombia R script](scripts/colombia/wwf_colombia_original.R)

## Brazil

For the Brazilian Amazon, I used R to examine deforestation in relation to land use, elevation, slope, roads, water, settlements, mining, and other geographic variables.

The [original Brazil script](scripts/brazil/wwf_brazil_original.R) contains the GLM specifications and the statistical analysis I worked on. I have not included a results table or map for Brazil.

## Scripts

I've kept the original scripts and added versions that allow the input and output paths to be specified when running them:

- [Colombia GLM script](scripts/colombia/colombia_glm_analysis.R)
- [Brazil GLM script](scripts/brazil/brazil_glm_analysis.R)

The updated scripts use named predictor columns and write model coefficients and evaluation files. They are not exact reproductions of the original analyses, particularly the RAC models and spatial validation procedures.

For Colombia:

```bash
Rscript scripts/colombia/colombia_glm_analysis.R --input data/colombia.csv --output-dir outputs/colombia
```

For Brazil:

```bash
Rscript scripts/brazil/brazil_glm_analysis.R --input data/brazil.csv --output-dir outputs/brazil
```

The input files must contain the required variables and a deforestation response coded as 0 or 1. More information on the expected inputs is in [data/README.md](data/README.md).

## Data availability

Original access to the data is not available at this time. I have kept the scripts and the results that I still have, but I cannot reproduce the original model outputs without those datasets.

The Colombia comparison table is a historical result, not an output generated by the updated scripts.
