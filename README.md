# Deforestation Research — Colombia and Brazil

I worked on deforestation-drivers research for WWF, examining how environmental conditions, accessibility, land use, and human activity relate to forest loss in Colombia and the Brazilian Amazon. This repository brings together my original R analyses, portable versions that do not depend on my old Windows directories, and the historical Colombia model-comparison table.

My objective was to compare candidate explanations for deforestation and assess how well statistical models performed, particularly when validation accounts for geographic structure.

## Colombia

In Colombia, I examined slope, elevation, distance to cities and roads, rivers, land-cover mosaics, protected areas, and agricultural activity. My historical analysis compared four binomial generalized linear model specifications:

- **Full:** the selected set of environmental and human-activity predictors.
- **Stepwise:** a reduced model selected from the full specification.
- **Naive:** an elevation-only baseline.
- **RAC:** a residual-autocovariate model intended to examine spatial dependence.

I also evaluated ROC/AUC, sensitivity, specificity, and True Skill Statistic, and investigated random and spatially grouped validation.

## Brazilian Amazon

For Brazil, I analyzed the relationship between deforestation and factors including elevation, slope, roads, water, population, indigenous territories, agricultural land use, mining, and other land-management characteristics. My original [Brazil R script](scripts/brazil/wwf_brazil_original.R) similarly fits Full, Stepwise, Naive, and RAC binomial GLMs, and includes repeated random and spatial cross-validation experiments.

The original analysis reads `Amazonia_2004_2017_03_24_sel_coord.xlsx`. I have not included that dataset or any historical Brazil figure or coefficient table, so the results cannot be reproduced from this repository alone.

## Running the portable scripts

I also created portable GLM workflows for [Colombia](scripts/colombia/colombia_glm_analysis.R) and [Brazil](scripts/brazil/brazil_glm_analysis.R). They use base R, configurable file paths, named predictors, and a stratified holdout split instead of relying on personal folders or positional column indices.

For Colombia:

```bash
Rscript scripts/colombia/colombia_glm_analysis.R \
  --input data/colombia.csv --output-dir outputs/colombia \
  --target Deforestation
```

For Brazil, first export the authorized original Excel dataset to CSV, then run:

```bash
Rscript scripts/brazil/brazil_glm_analysis.R \
  --input data/brazil.csv --output-dir outputs/brazil \
  --target DEFORESTATION --baseline ELEVATION_SRTM90_AMAZONIA
```

Both scripts require a binary target encoded as 0/1, the baseline elevation column, and numeric predictor columns. To select predictors explicitly, use `--predictors Slope,Elevation,Main_Cities_Dist` (with names appropriate to the country dataset). Use `--distances-in-metres true` only when distance columns are actually in metres.

Outputs include model coefficients, holdout predictions, and holdout metrics. When coordinate columns are available, the scripts can also attempt simplified geographically grouped validation.

## What is and is not reproducible

I retained the original scripts to document the methods I used. The portable versions implement **Full, Stepwise, and Naive GLMs**, but do **not** exactly reproduce the original RAC specification, HC3 robust standard errors, 10 × 10 repeated cross-validation, or the original spatial clustering method. Their simplified geographic folds and 0.5 decision threshold are deliberate changes, so new results will not necessarily match the historical tables.

The original code used specific datasets, factor conventions, and column selections. Reproducing the published or historical numerical results requires the authorized input data and a matching R package environment. I have not rerun the portable scripts against those datasets.

The historical Colombia map is a Random Forest result; it should not be presented as a visualization generated by the GLM script.
